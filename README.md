# Siłka

Czysta wersja dziennika treningowego (gałąź `silka`): bez planów i bez danych — zaczynasz od zera.
Wbudowana baza ćwiczeń zostaje, plany tworzysz sam w zakładce Plany.

**Pobierz:** https://github.com/aipiotrlipinski/gym-lipka/releases/download/silka-apk/silka.apk

Osobna aplikacja (`pl.lipka.silka`) — instaluje się obok Gym Lipka i nie rusza jej danych.
Każdy push do gałęzi `silka` buduje nowe APK pod tym samym adresem.
